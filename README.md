Repositorio académico con las actividades y evidencias de la asignatura **Gestión de Proyectos de Software**.

| | |
|---|---|
| **Carrera** | Ingeniería en Sistemas Computacionales |

| **Estudiante** | Amaury Jahaziel Gordillo Hernández |

## Objetivo del repositorio

Reunir en un solo lugar, ordenado por tema, los documentos, presentaciones, formatos y evidencias que se entregan en la asignatura, para que puedan consultarse con facilidad.

Las prácticas se desarrollan sobre **Joinfy**, una plataforma de invitaciones digitales con confirmación de asistencia, boletos con código QR, administración de invitados y mesas, y envío por WhatsApp. Es el proyecto que se usa como caso de estudio para planear, documentar y evaluar la calidad de un producto de software real.
